# Лендинг: клинический психолог Пётр Суханов

HTML5 + CSS + JavaScript (без сборки) и PHP 8.1+ для приёма заявок.

## Структура
```
index.html               — сама страница
privacy.html             — политика конфиденциальности (шаблон, заполнить)
assets/css/style.css     — оформление (цвета — в начале файла)
assets/js/logger.js      — модуль логирования (браузер)
assets/js/main.js        — форма, маска телефона, цели Метрики, UTM-метки
assets/img/              — сюда фото: photo.jpg, og-image.jpg (1200×630)
assets/img/certificates/ — сюда сертификаты: cert-1.jpg, cert-2.jpg ...
api/send.php             — приём заявки → таблица + письмо
api/log.php              — приём ошибок из браузера
api/Logger.php           — модуль логирования (сервер)
api/config.example.php   — пример настроек → скопировать в config.php
data/leads.csv           — ТАБЛИЦА ЗАЯВОК (создастся сама, открывается в Excel)
data/logs/               — логи (создадутся сами)
docs/                    — инструкции: Яндекс Директ, ИИ-ассистент
```

## Что заполнить перед запуском (поиск по «[» в файлах)
- [ ] Фото и сертификаты в `assets/img/`
- [ ] Образование и опыт в блоке «Обо мне»
- [ ] **Настоящие** отзывы клиентов (с их согласия)
- [ ] Цена и длительность в FAQ
- [ ] ФИО/ИНН в подвале и в `privacy.html`
- [ ] `api/config.php` (почта для заявок)
- [ ] Номер счётчика Метрики в `index.html`
- [ ] Домен в `<link rel="canonical">`

## Публикация
Подойдёт любой российский хостинг с PHP 8.1+ и Apache (например, Beget, Timeweb, REG.RU). Скопируйте все файлы в папку сайта (обычно `public_html`) и проверьте, что `https://домен/data/leads.csv` **не открывается** (должна быть ошибка 403).
