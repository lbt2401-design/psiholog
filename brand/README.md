# Папка бренда (шаблон)

Здесь хранится всё, из чего складывается внешний вид сайта клиента: логотип, цвета, шрифты.
Сайт **не придумывает** цвета и шрифты сам: он берёт их только отсюда.
Поменяли цвет в `tokens.css`, и он поменялся на всём сайте.

## Что внутри

| Файл | Зачем |
|---|---|
| `brief.md` | Анкета клиента: кто он, для кого сайт, идея стиля. Заполняется **первым**. |
| `tokens.css` | Цвета, шрифты, размеры, скругления. Имена переменных не менять. |
| `logo/logo-mark.svg` | Знак (значок без текста), холст 64×64. |
| `logo/logo-mark-inverse.svg` | Знак для тёмного фона. |
| `logo/logo.svg` | Знак + название одним файлом: документы, соцсети. |
| `logo/favicon.svg` | Иконка во вкладке браузера. |
| `preview.html` | Бренд-гид: страница, где всё видно разом. Её показываем клиенту на утверждение. |

## Как сделать бренд для нового клиента

1. Скопировать эту папку в проект клиента под именем `brand/`.
2. Заполнить `brief.md`.
3. Придумать стиль **из мира клиента** (материалы, предметы, слова его дела), а не из шаблонов ниши.
4. Вписать значения в `tokens.css`, нарисовать знак в `logo/`.
5. В `preview.html` заполнить блок `window.BRAND` (имя, заголовок, правила).
6. Открыть `preview.html` и проверить: логотип читается в 16px, текст контрастный, на телефоне ничего не съезжает.
7. Показать клиенту и отметить утверждённое в `brief.md`.
8. Только после этого верстать сайт.

## Как подключить к сайту

В `<head>` каждой страницы, **до** основного CSS:

```html
<link rel="preconnect" href="https://fonts.googleapis.com">
<link rel="preconnect" href="https://fonts.gstatic.com" crossorigin>
<link rel="stylesheet" href="brand/tokens.css">
<link rel="icon" href="brand/logo/favicon.svg" type="image/svg+xml">
<link rel="stylesheet" href="assets/css/style.css">
```

Логотип в шапке собирается из знака-картинки и текста (так шрифт подгружается корректно):

```html
<a href="/" class="logo">
  <img src="brand/logo/logo-mark.svg" alt="" width="40" height="40">
  <span>Название<small>чем занимается</small></span>
</a>
```

В CSS сайта только переменные:

```css
.btn--primary { background: var(--color-primary); color: var(--color-on-primary); border-radius: var(--radius-pill); }
h1 { font: var(--fw-head) var(--fs-h1)/var(--lh-head) var(--font-head); }
```

## Подводные камни
- **Шрифты в `logo.svg`** берутся с компьютера зрителя. Если шрифта нет, покажется запасной. Для печати текст нужно перевести в кривые (в Figma / Illustrator / Inkscape).
- **Google Fonts** подключены через `@import` в `tokens.css`: так всё хранится в одном месте, но страница грузится чуть медленнее. Для боевого сайта можно скачать шрифты к себе (папка `assets/fonts/`) — быстрее и без обращений к Google.
- **Светлый акцент** (`--color-highlight`) часто не читается как текст на светлом фоне. Использовать его только для декора.
